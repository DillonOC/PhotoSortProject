| Priority | Location / field                                                                             | Why                                                                                                                                                                                                                                                                                                          |
| -------- | -------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **1**    | **EXIF `DateTimeOriginal`**                                                                  | Specifically represents when the original image was created/taken. This remains your best source.                                                                                                                                                                                                            |
| **2**    | **XMP `exif:DateTimeOriginal`**                                                              | XMP representation of the same concept. Useful if EXIF has been removed but XMP retained.                                                                                                                                                                                                                    |
| **3**    | **IPTC `DateCreated` + `TimeCreated`**                                                       | Explicitly defined as when the **content of the image was created**, rather than when the digital representation was created. IPTC's own help text says this is the date the image was taken. ([IPTC][1])                                                                                                    |
| **4**    | **XMP `photoshop:DateCreated`**                                                              | XMP equivalent of the IPTC Date Created concept, so this is also explicitly about creation of the image content. ([IPTC][1])                                                                                                                                                                                 |
| **5**    | **EXIF GPS `GPSDateStamp` + `GPSTimeStamp`**                                                 | GPS receiver date/time in UTC. This can be excellent supporting capture-time evidence when both are present. The EXIF specification says `GPSTimeStamp` is the GPS reference time in UTC and `GPSDateStamp` supplies its date. ([studylib.net][2])                                                           |
| **6**    | **EXIF `DateTimeDigitized`**                                                                 | Time the image was digitised. On a digital camera/phone this is commonly the same moment it was taken, but for scanned or converted images it may not be. ExifTool calls this `CreateDate`; `metadata-extractor` calls it `TAG_DATETIME_DIGITIZED`. ([javadoc.io][3])                                        |
| **7**    | **HEIC/HEIF QuickTime `Keys:CreationDate` / `com.apple.quicktime.creationdate`**, if present | This is the important format-specific one I was referring to. Apple's QuickTime-style metadata can carry a creation date including timezone. However, HEIC files often simply use EXIF timestamps instead, so don't expect this field to always exist. HEIC is QuickTime/ISO-BMFF based. ([exiftool.org][4]) |
| **8**    | **XMP `xmp:CreateDate`**                                                                     | Date the digital resource was created. Often useful, but it is not as explicitly “photo was taken at this time” as `DateTimeOriginal` or IPTC `DateCreated`.                                                                                                                                                 |
| **9**    | **EXIF IFD0 `DateTime` / ModifyDate**                                                        | Often identical to capture time in untouched camera photos, but semantically it is a modification timestamp. Editing software can change it. This is where I should have put it originally — quite a long way down.                                                                                          |
| **10**   | **QuickTime `CreateDate`**                                                                   | HEIC/HEIF containers *may* expose this. It represents creation of the QuickTime/container structure and isn't inherently a camera shutter timestamp.                                                                                                                                                         |
| **11**   | **QuickTime `TrackCreateDate` / `MediaCreateDate`**                                          | Even more container/media-structure orientated. Useful only as a weak fallback. These timestamps can change or become misleading after syncing/transcoding/editing. ([exiftool.org][5])                                                                                                                      |
| **12**   | **PNG textual `Creation Time` / `CreationTime`**                                             | PNG can have textual metadata such as `"Creation Time"`, but it isn't a strong standardised camera-capture field. `metadata-extractor` can expose PNG textual data. ([GitHub][6])                                                                                                                            |
| **13**   | **Filesystem creation/birth time**                                                           | When the OS says this particular file was created. Copying/restoring/downloading can change it.                                                                                                                                                                                                              |
| **14**   | **Filesystem last-modified time**                                                            | Last-resort guess only.                                                                                                                                                                                                                                                                                      |
| **15**   | **Unknown**                                                                                  | Better than assigning a misleading date if nothing credible exists.                                                                                                                                                                                                                                          |
